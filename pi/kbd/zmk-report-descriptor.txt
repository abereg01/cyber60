# ZMK_POINTING), read on the Pi from /sys/class/hidraw/<n>/device/report_descriptor
# on 2026-11-05. Identical over Bluetooth (HOG) and USB. 176 bytes.
#
#   ID 1  keyboard  8 bytes: modifier bits, reserved, 6 key codes (0-255).
#                   The boot keyboard layout. No LED output report.
#   ID 2  consumer  12 bytes: 6 x 16-bit usages (0-0xFFF)
#   ID 3  mouse     9 bytes: 5 buttons + 3 pad bits, X, Y, wheel, AC pan
#                   (each 16-bit signed)
#
# Reports arrive on hidraw with the ID as their first byte.
#
# The Pi's USB gadget (image/files/deck-drive.sh) uses the ID 2 and ID 3 part
# (bytes 51-176) as /dev/hidg1's descriptor as it is, so those reports pass
# through unchanged (tools/test-drive.sh checks they match). ID 1 goes to
# /dev/hidg0, a boot keyboard of its own (with the LED output report), without
# its ID byte.
